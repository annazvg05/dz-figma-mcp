Текстовый отчёт

Анализ работы с MCP-сервером

1

Какую задачу решала с помощью MCP-сервера

Тестировала возможность автоматического создания дизайн-блоков в Figma средствами ИИ-агента. Задача: попросить агента создать футер для сайта стоматологической клиники Re_stom, сохраняя стилистику существующего дизайна — цвета, шрифты, компоновку.

2

Какой MCP-сервер выбрала

Официальный Figma MCP Server — разработан командой Figma, подключается к Claude Code, Cursor и другим MCP-клиентам. Работает через Figma Plugin API и REST API.

3

Почему выбрала именно его

Figma — основной инструмент в моей работе. Хочу использовать ИИ-агента для:

  • Быстрого создания новых блоков и прототипов без ручной работы
  • Массовой замены шрифтов и цветов по описанию
  • Генерации идей анимации при переносе дизайна на Тильду
  • Ускорения рутинных операций в дизайн-процессе

4

Какие данные, сервисы или функции он добавил агенту

MCP-сервер расширил агента двумя группами возможностей:

  • Чтение дизайна — получение скриншотов фреймов, структуры слоёв, токенов стиля (цвета, шрифты, отступы), метаданных файла
  • Запись в Figma — создание и редактирование фреймов, текстовых слоёв, фигур и компонентов через Figma Plugin API прямо из чата

5

Какой первый результат удалось получить

Агент самостоятельно проанализировал дизайн существующей страницы через инструмент get_design_context, извлёк цветовую палитру (#201e1f, #bead9a) и шрифты, затем через use_figma создал фрейм Footer (1200×300px) с:

  • Логотипом Re_stom и слоганом
  • Навигацией в две колонки (7 пунктов)
  • Выделенным номером телефона на золотом фоне
  • Адресом, email и часами работы
  • Копирайтом и политикой конфиденциальности

6

Помог ли MCP-сервер решить задачу и почему

Да, частично. Агент успешно прочитал стиль существующего дизайна и создал блок, выдержанный в той же стилистике — без ручного подбора цветов и вёрстки в Figma. Это подтверждает основную гипотезу: агент может работать как ассистент дизайнера для создания новых блоков.

Ограничения, с которыми столкнулась: лимит MCP-запросов на Starter-плане Figma не позволил сделать скриншот результата прямо из агента (лимит сбрасывается ежедневно). Шрифт Inter Tight оказался недоступен в плагине — агент адаптировался и использовал Inter с настройкой letter-spacing. В целом инструмент рабочий и перспективный для регулярного использования.
